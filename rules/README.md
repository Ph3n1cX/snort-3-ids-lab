# Snort Rules

Store only rules you wrote or are permitted to redistribute, with a note about their source and purpose.

For each rule, document:

- Rule filename and purpose
- What traffic or event it is intended to match
- Explanation of the rule options
- How it was validated in the isolated lab
- Actual result and evidence link
- Known limitations and likely false positives

Do not claim a rule detected traffic until you have tested it and captured the observed output.

No custom rules have been documented in this directory yet.
